# 白底图获取工具

在 macOS 上运行，使用本机的 Ego Browser 读取中关村在线（ZOL）手机产品和图库。

## 使用

1. 双击「启动白底图工具.command」，浏览器会打开本机页面。保持打开启动时的终端窗口。
2. 上传 `缺图名单.xlsx`，或切换到「粘贴清单」，一行填一个型号或 ZOL 链接。粘贴时也可用 Tab 分隔品牌和型号。
3. 点击「开始采集」。抽样仅处理选出的型号，全量请在导入前选择「全部型号」。
4. 展开型号可查看每个颜色的选图和候选。对「待确认型号」可核对 ZOL 搜索结果，再粘贴正确的产品页或图库链接并继续采集。
5. 点击「下载 ZIP」，查看按型号分目录的 JPG 和 `采集结果.csv`。有候选图的待复核项会随 ZIP 下载，放在型号下的「待复核」目录。表格记录状态、视角、来源和备注。

暂停会在当前型号结束后生效。批次进度保存在本目录的「批次」下，重新启动工具后可以继续。

## 选图规则

- 型号匹配接受「5G 版」「5G 款」等常见后缀写法。标题没有明确列出网络或芯片时，工具可通过对应 ZOL 参数页核实版本。
- 从 ZOL 型号页和图库读取颜色。对外观图及官方图先核对颜色，再优先选近似正背同框的白底图，其次选近似单面的。颜色无法核实时，符合白底和水印要求的图片仍会导出到该型号的「未标色」目录，按编号命名，清单中的颜色留空。构图暂时无法确认的图片也会保存，并在清单中保留构图状态。
- 未标色且构图未确认的图片会检查是否有可辨认的手机轮廓，以排除白底宣传素材。
- 以主体居中的方式输出 800 × 800 JPG。对贴近边缘的手机，直接用原图边缘的像素复核白底。工具在原图右下区域检查 ZOL 水印。能定位且在主体框外的水印会随原背景裁去。搜索没有发现可疑痕迹且右下留白干净时，可直接出图。
- 视角由机身外边缘、两台手机之间的间隙或接缝、屏幕边框和后摄区域的图像特征估计。色调差异也会用于发现疑似同框的候选。
- 正背同框候选和有同框特征的待确认候选会排在单面图之前。构图和水印的复核原因会分别显示，可查看候选后手动选用。

## 命令行启动

在已安装 Python 3.10+、Ego Browser 的电脑上，从工具目录运行。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py --open
```

默认地址为 `http://127.0.0.1:8765`。需要换端口时传入 `--port 8766`。
