接口一览

接口说明
GET /api/v1/images图片列表，支持品牌组 / 品牌 / 型号 / 颜色 / 状态筛选与分页
GET /api/v1/images/{id}单张图片详情
GET /api/v1/images/{id}/file原图，加 ?w=320 返回缩略图
GET /api/v1/images/{id}/download下载，使用标准文件名
GET /api/v1/images-facets品牌组 / 品牌 / 颜色 / 状态聚合，计数随筛选上下文实时计算
GET /api/v1/brand-tree统一品牌选择器数据：品牌组（含子品牌）与独立品牌
GET /docs接口文档（中文，需登录）
