图片资产管理平台 API 接入指南

提供商品信息，调用一个图片查询接口，就能拿到可用图片的信息，再按授权方式取图。 图片查询使用 GET /api/v1/images；商品上架素材对接使用 业务对接接口，支持型号查询、素材解析、批量预检和原图下载。

能做什么

按商品信息查询图库中的图片，供业务系统程序化调用。

传入商品的品类、品牌、型号、颜色，接口返回匹配到的图片清单：每张图的图片 ID、品牌、型号、颜色、尺寸， 以及取图和下载的地址。

适合用在商品上架、素材整理、批量导出这类需要自动取图的流程里。

支持的筛选维度

品类 手机 / 平板电脑 / 智能手表 / 笔记本

品牌 例如 Apple、华为、小米

型号 可按型号关键词查找；需要精确标准型号时使用 model_exact，并可指定 model_source

颜色 例如 蓝色、冰川蓝色

直接按商品信息查询

品牌、型号、颜色可组合筛选。型号与颜色覆盖持续扩展，按需传入已知值查询，不需要在接入端维护固定组合清单。

i

接口只返回已确认可用的素材；未确认、已停用或受限的素材不会出现在结果里。 需要登录后才能调用，具体见 怎么拿到图片。

怎么调用

先登录拿会话，再用一次 GET 请求查询。

  1. 登录，拿到会话 Cookie

    图库使用账号登录，没有 API Key。登录成功后服务端下发会话 Cookie，后续请求带上它即可。

    curl 
    curl -c cookies.txt -X POST https://picsystem.changziqi.com/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  --data-urlencode "username=你的账号" \
  --data-urlencode "password=你的口令"

  2. 用商品信息查询图片

    四个维度都可以组合，不传就是全部。下面的例子查「Apple / iPhone 14 / 蓝色」：

    curl 
    curl -b cookies.txt \
  "https://picsystem.changziqi.com/api/v1/images?brand=Apple&model=iPhone%2014&color=%E8%93%9D%E8%89%B2&limit=10"
    python 
    import requests                     # pip install requests

BASE = "https://picsystem.changziqi.com"
s = requests.Session()
s.post(f"{BASE}/login",
       data={"username": "你的账号", "password": "你的口令"},
       allow_redirects=False)        # 返回 303 即登录成功

r = s.get(f"{BASE}/api/v1/images",
          params={"brand": "Apple", "model": "iPhone 14", "color": "蓝色", "limit": 10})
r.raise_for_status()
data = r.json()
print("共", data["total"], "张")

for item in data["items"]:
    print(item["id"], item["display_color"], item["width"], "x", item["height"])

可用的查询参数

全部可选；只写你确定的那几个就够了。

参数填什么说明示例
category 品类 默认 phone（手机）。其他：tablet 平板、watch 手表、laptop 笔记本。 phone
brand 品牌 精确匹配，写图库里显示的品牌名。 Apple
model 型号 按图库型号名称模糊匹配。需要限定标准型号时可用 model_exact；目录原始型号可用 model_exact 配合 model_source=directory。列表接口当前没有 model_id 查询参数。 iPhone 14
q 关键词 在品牌、型号、目录型号和颜色中模糊搜索。 iPhone 14
group 品牌组 按品牌组筛选：xiaomi、vivo、oppo。 xiaomi
status 匹配状态 按图库匹配状态精确筛选；仅在业务确有此需求时使用。 matched
asset_kind 图片用途 当前唯一用途分类字段；例如白底图库查询传 white。生产端的图片用途、覆盖统计和待确认池均以此字段为准。历史 asset_type 仅保留兼容，不作为筛选或分类依据。 white
color 颜色 精确匹配。 蓝色
limit / offset 分页 每页条数 1～200（默认 60）；从第几条开始，默认 0。 10 / 0

白底图库查询应使用 asset_kind=white；分类依据是 asset_kind，历史 asset_type 只兼容旧调用，不再参与分类。型号×颜色组合会随图库更新；返回中的 model_id、standard_color 是核对精确组合的依据。列表以 limit / offset 分页，必须遍历到 total 覆盖完整结果。

型号与颜色组合

组合规模较大且会变化，接入方不应把完整的型号×颜色清单固化在程序或本文档中。需要枚举时，按已知型号筛选后分页读取，并从返回记录提取 model_id 与 standard_color。

当前 GET /api/v1/images 支持型号名称模糊参数 model、标准/目录型号精确名称 model_exact 和来源 model_source，但不支持通过 model_id 直接筛选。用 Gaia ID 对账时，应核对返回记录中的 model_id。

颜色筛选 color 为精确匹配展示颜色；验证标准颜色组合时，应使用响应记录中的 standard_color 字段，不要仅凭展示色名推断等价。

返回什么

返回 JSON，每张图一条记录。下面是真实响应（只保留业务关心的字段）。

json 
{
  "total": 1,
  "limit": 10,
  "offset": 0,
  "items": [
    {
      "id": "img_25807e9a7151",
      "display_brand": "Apple",
      "model_name": "苹果 iPhone 14",
      "display_color": "蓝色",
      "format": "JPEG",
      "width": 1600,
      "height": 1600,
      "size_bytes": 408896,
      "can_view_original": true,
      "can_download": true,
      "file_url": "/api/v1/images/img_25807e9a7151/file",
      "thumb_url": "/api/v1/images/img_25807e9a7151/file?w=320",
      "download_url": "/api/v1/images/img_25807e9a7151/download"
    }
  ]
}

业务需要关心的字段

字段含义
total 符合条件的图片总数，用于判断要不要翻页。
items[].id 图片 ID。取图、下载时用它拼地址。
items[].display_brand 品牌，例如 Apple。
items[].model_name 标准型号，例如 苹果 iPhone 14。
items[].display_color 颜色，例如 蓝色。
items[].format / width / height / size_bytes 格式、像素宽高、文件大小（字节），用于判断素材是否满足投放要求。
items[].file_url 取原图的相对地址。拼上站点域名即可请求。
items[].thumb_url 缩略图地址（宽 320 的 WebP），适合列表展示。
items[].download_url 下载地址，返回带规范文件名的附件。
items[].can_view_original / can_download 这张图当前是否允许看原图、是否允许下载。为 false 时只可用缩略图。

接口不返回服务器本地路径，也不会返回内部治理字段；取图请一律使用上面三个 url 字段。

怎么拿到图片

查询接口返回的是图片信息，不是图片文件本身 —— 取图需要再发起一次请求。

!

这一点必须说清楚：GET /api/v1/images 只返回 JSON（ application/json），不会直接返回图片字节。要拿到图，用返回里的 file_url 或 download_url 再请求一次，并且同样要带登录会话。

方式一：取原图（用于预览、后续处理）

请求 file_url，返回图片本身。加 ?w=320 返回缩略图。

curl 
curl -b cookies.txt -o image.jpg \
  "https://picsystem.changziqi.com/api/v1/images/img_25807e9a7151/file"

方式二：下载（用于交付、归档）

请求 download_url，服务端会带上规范文件名。

curl 
curl -b cookies.txt -OJ \
  "https://picsystem.changziqi.com/api/v1/images/img_25807e9a7151/download"

完整流程（查询 → 取图）

python 
import requests

BASE = "https://picsystem.changziqi.com"
s = requests.Session()
s.post(f"{BASE}/login", data={"username": "你的账号", "password": "你的口令"},
       allow_redirects=False)

items = s.get(f"{BASE}/api/v1/images",
              params={"brand": "Apple", "model": "iPhone 14", "limit": 1}).json()["items"]

first = items[0]
if not first["can_download"]:
    raise SystemExit("这张图当前不允许下载，只能使用缩略图")

img = s.get(BASE + first["download_url"])
img.raise_for_status()
open("image.jpg", "wb").write(img.content)
print("已保存", first["display_brand"], first["model_name"], first["display_color"])

权限与访问范围

登录方式：账号 + 口令，服务端下发会话 Cookie（HttpOnly）。目前没有 API Key， 也不支持 Bearer 令牌；未登录访问会返回 401。

适用范围：适合人工登录后的操作，以及同一会话内的脚本和内部工具； 暂不适合其他系统用固定凭据长期无人值守对接 —— 这类能力需要另行立项补齐。

素材范围：只返回已确认可用的素材；未确认、已停用或受限的素材不通过本接口开放。 can_view_original / can_download 为 false 时，说明该素材当前只允许缩略图预览。

业务接口对接 · 独立服务

当前对接接口使用图库已有登录 Cookie，未登录返回 JSON 401。当前支持手机型号查询、素材解析、预检和下载；不提供上传、审核或删除操作。

图片准入口径（2026-11-26 起）

白底图库中 quality_level=A 的图片即业务可用，quality_flags 不再参与准入判定。历史批次标记格式不同、或标记为空，都不再影响调用方判断。

接口返回的 quality_flags 统一为固定 5 键结构，可直接按下列字段校验：

{
  "white_background": "yes",
  "single_product": true,
  "marketing_or_watermark": "no",
  "model_mismatch_suspicion": "none",
  "human_review": "confirmed"
}

结论来源见 review_basis：per_image_human_approved 为逐图人工确认，business_batch_confirmed_20261126 为业务批量确认，shop_main_image_not_subject_to_white_audit 为店铺主图（不做白底审核）。

技术门槛保持不变：正方形且短边不少于 600 像素、单张不超过 3,000,000 字节、格式为 JPEG/PNG/WebP，并满足型号与 Gaia 标准颜色匹配。不满足时 eligibility_status 为 ineligible，原因写在 reject_reasons。

图片关键字段

字段取值含义
quality_levelA业务可用等级。
eligibility_statuseligible / ineligible / unknown能否用于上架；unknown 仅在原图文件当前不可读时出现。
douyin_eligibletrue / false与 eligibility_status 同义的布尔值。
quality_flags固定 5 键审核结论，结构见上。
review_basis枚举结论来源，便于审计。
publish_statepublished手机类目不做发布流程，A 级即视为已发布。
rights_statusconfirmed按业务方项目级授权自动确认。
usable_scopeplatform_listing允许用于平台上架。
external_use_allowedtrue允许外部平台使用。
reject_reasons数组不可用原因；可用时为空数组。

型号匹配

支持三种入参：只传 model_id；或同时传 brand 与 model；或只传完整 model 名称。品牌名支持「华为」和「华为（HUAWEI）」两种写法。型号存在多个精确候选时返回 409 MODEL_AMBIGUOUS 与候选列表，不自动选择。

方法路径能力
GET/openapi/v1/listing/models型号候选与精确查询
POST/openapi/v1/listing/resolve单商品素材解析
POST/openapi/v1/listing/precheck最多 50 条批量预检
GET/openapi/v1/listing/images/{image_id}/file原图字节、ETag 与条件下载
